# 智慧树单元测试助手（公开版）v0.2.0

一个 Windows 小工具：用 UI Automation 读智慧树/在线学堂考试页，把你选的模型（任意 OpenAI 兼容接口）接进来批量作答。

**它不会自己提交。** 一套题填完就停，自动核对答题卡并把未答题号列给你，补完再点「提交（需确认）」。

## v0.2.0 改了什么

| 问题 | 处理 |
| --- | --- |
| 窗口挡住浏览器，导致识别/点击失败 | 不再置顶；默认停靠屏幕右下角；点「自动作答」后窗口**收进托盘**，浏览器全程不被遮挡；每 9 题重新激活浏览器一次 |
| 重做时重复点击，把已选项又点掉 | 作答改为**先读当前选中状态，只点差异项**：目标 - 已选 = 要点；已选 - 目标 = 要取消；点完再回读校验，不一致会提示 |
| 图片题被无脑跳过 | 「图片题」单选：**跳过** / **停留等我做**（停下弹窗，你在浏览器选好后点确定继续） |
| 不知道还有哪些没做 | 结束时 + 提交前自动**逐题回读**核对，输出「未作答：7, 15, 17」；「跳到第一道未答」一键定位；未答时二次确认里直接列题号 |

## 特性

- 模型可换：API Base URL + Model + API Key，任何 `POST /chat/completions` 都能接（DeepSeek、OpenAI、通义、Moonshot、本地 vLLM/Ollama）。
- 幂等作答：同一题重复运行不会把已选项点掉。
- 图片题不猜图：只导航或停下等你。
- 提交前核对：完成率 < 100% 会先扫描再弹确认。
- 慢速作答：每题随机停顿 1.2–2.4 秒，每 9 题多停 2–4 秒。

## 运行

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-ExamHelper.ps1
```

## 用之前

1. 浏览器打开考试页，**不要最小化**。
2. 页面缩放调到能一屏一题的档位（75% 好用）：`Ctrl+0` 后按几次 `Ctrl+-`。
3. 先点「读取当前题」，能读出题干、选项、以及「当前已选」才算环境 OK。

## 三栏配置

| 字段 | 说明 |
| --- | --- |
| API Base URL | 如 `https://api.deepseek.com/v1`；程序拼 `/chat/completions` |
| Model | 如 `deepseek-chat`、`gpt-4o-mini` |
| API Key | 只在内存中使用，不落盘、不写日志 |

## 使用流程

1. 填三栏 →（可选）选图片题策略 → 点「自动作答」。
2. 程序逐题：读题 → 问模型 → **先判已选、只点差异** → 点「下一题」保存。
3. 结束弹窗：作答 N 题、图片题题号、**仍未作答的题号**。
4. 补完（图片题自己看图选）→ 点「检查答题卡」复核 → 点「提交（需确认）」。

## 判读原理与前提

- 题目与选项文字来自 UI Automation；**是否已选**没有暴露给 UIA，所以用屏幕采样：取选项字母左侧 4–24px 的带状区域，若出现明显蓝色（B−R>35 且 B>110）即认为已选。
- 因此前提是**浅色主题 + 未开强制暗色模式**；缩放建议 75%（当前阈值按此标定）。换缩放或换主题后若判读不准，改 `Test-BlueAt` 的阈值和 `Get-SelectedLetters` 里的 `-24 / -4` 偏移即可。
- 答题卡核对是「逐个跳到 1..N 题、回读该题选项状态」，比单纯看完成率更准，但一套 50 题约需 60–90 秒。

## 已知限制

- 只支持「一屏一题 + 点下一题翻页」的页面结构。
- 选项顺序每次随机，所以每次现场读、现场点，不复用旧字母。
- 模型偶尔只给一个字母或给不出字母，日志会标出来，需人工补。
- 窗口被别的窗口完全遮挡时采样会读到别的窗口，程序开始与中途都会把浏览器切前台，但仍建议答题时别开置顶的其它窗口。
