# 智慧树单元测试助手（公开版）

一个 Windows 上的小工具：用 UI Automation 读取智慧树/在线学堂考试页面，把你选的模型（任意 OpenAI 兼容接口）接进来批量作答。

**它不会自己提交。** 一套题填完就停下，让你先看右侧答题卡（蓝色=已答，黑色=未答），补完再点「提交」。

## 特性

- 模型可换：API Base URL + Model 名 + API Key 三栏，任何 OpenAI 兼容的 `POST /chat/completions` 都能用（DeepSeek、OpenAI、通义、Moonshot、本地 vLLM/Ollama 等）。
- **图片题不做**：检测到选项是图片（只有 `A.`/`B.`/`C.`/`D.` 没有文字）就跳过、只记录题号，留给你自己看图选。
- **填完必须人工检查**：不自动提交；提交按钮带二次确认。
- 慢速作答：每题随机停顿 1.2–2.4 秒，每 9 题多停 2–4 秒，可在设置里改。
- 全程写日志，可随时「停止」。

## 运行

```powershell
# Windows PowerShell 5.1 或 PowerShell 7 均可
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-ExamHelper.ps1
```

首次运行可能需要 `Set-ExecutionPolicy -Scope Process Bypass`。

## 用之前

1. 浏览器打开考试页面，**不要最小化**，窗口保持在前台。
2. 页面缩放调到能一屏一题的档位（75% 好用）：`Ctrl+0` 然后几次 `Ctrl+-`。
3. 工具里先点「读取当前题」验证能读到题干和选项；读不到说明该页面 UIA 不透出文本，本工具不适用。

## 三栏配置

| 字段 | 说明 |
| --- | --- |
| API Base URL | 例如 `https://api.deepseek.com/v1`、`https://api.openai.com/v1`；程序会拼 `/chat/completions` |
| Model | 例如 `deepseek-chat`、`gpt-4o-mini`、`qwen2.5-72b-instruct` |
| API Key | 只在内存里用，不落盘、不写日志 |

## 使用流程

1. 填三栏 → 点「自动作答（跳过图片题）」。
2. 工具逐题：读题 → 问模型 → 点选项 → 点「下一题」保存。
3. 结束时弹出提示：已答 N 题、跳过 M 道图片题（列出题号）。
4. 你切到浏览器，看右侧答题卡把黑色题补掉（图片题自己看）。
5. 回到工具点「提交（需确认）」→ 二次确认 → 完成。

## 已知限制

- 只支持「一屏一题 + 点下一题翻页」的页面结构；整页长列表的页面需要自己改。
- 选项顺序是随机的，所以每次都现场读、现场点，不能复用上一次的答案字母。
- 多选题模型偶尔只给一个字母，日志里会标出来，你可以手动补。
- 页面被别的窗口挡住时点击会打偏，工具在开始时会激活浏览器窗口，中途每 9 题再激活一次。
